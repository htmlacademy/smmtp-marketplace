# Amplify

Публикует Markdown-пост сразу на несколько площадок через сервис, сначала показывая превью. Работает в Claude Code, Codex и Claude Cowork.

```
/plugin install amplify --marketplace htmlacademy/smmtp-marketplace
```

Остальные способы установки, включая отдельные скиллы через `npx skills`, — в [README маркетплейса](../../README.md).

## Скиллы

| Скилл | Что делает |
|---|---|
| `amplify:setup` | по адресу сервиса, имени аккаунта и секрету подключает каналы шаг за шагом, проверяет каждый через `doctor`; находит, что сломалось, когда публикация упала на настройке |
| `amplify:crosspost` | показывает превью поста по каждой площадке, спрашивает, публикует один раз и отдаёт ссылки |

Просите словами, «настрой кросспостинг в телеграм» или «опубликуй content/2026-09-13-release в телеграм и bluesky», или зовите скилл по имени: `/amplify:setup` в Claude Code, `$amplify:setup` в Codex.

Пост — это `content/<date>-<slug>/index.md`, только Markdown. Картинки и видео из той же папки уходят вместе с постом, если не сказать иначе. Строка `::media{id="cover.png"}` размещает файл в этом месте текста, а `::media{ids="a.png,b.png" layout="slideshow"}` или `layout="collage"` — несколько файлов одной группой, на площадках, которые умеют держать файл на месте. По умолчанию это обычный пост; рилс или сторис — по просьбе. Для Telegram попросите расширенное форматирование или статью, чтобы сохранить заголовки, таблицы и списки в формате Rich Message. Текст длиннее лимита площадки можно опубликовать цепочкой постов там, где они есть.

## Настройка

Адрес сервиса, имя аккаунта и секрет выдаются на https://smmtp.ru, вопросы — на mail@smmtp.ru. Запустите `amplify:setup` и дайте ссылки на свои каналы. Сервис хранит ключи площадок в подключённых каналах; настройка подключает каждый канал по ключу, который вы передадите, или через вход в аккаунт площадки. Для публикации скрипт выпускает отдельный токен.

Значения живут в `.smmtp/.env.local` проекта или в `~/.smmtp/.env.local` для всех проектов в домашней папке; `.smmtp/.env.example` рядом — пример без секретов, которым можно делиться. Оба файла начинаются с размеченного шаблона [scripts/config.template](scripts/config.template). Каждый секрет идёт туда, куда выберете: в чат, в файл руками или в связку ключей macOS. После подключения канала скрипт убирает его ключи из файла. Подробности — [configuration.md](skills/setup/references/configuration.md), как подключить каждую площадку — [platforms.md](skills/setup/references/platforms.md).

Команды, переменные и коды выхода, из этой папки:

```bash
python3 scripts/amplify.py --help
```

Python 3.9 или новее, только стандартная библиотека.
