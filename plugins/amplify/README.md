# Amplify

Публикует Markdown-пост сразу на несколько площадок через сервис, сначала показывая превью. Работает в Claude Code, Codex и Claude Cowork.

```
/plugin install amplify --marketplace htmlacademy/smmtp-marketplace
```

Остальные способы установки, включая отдельные скиллы через `npx skills`, — в [README маркетплейса](../../README.md).

## Скиллы

| Скилл | Что делает |
|---|---|
| `amplify:setup` | по шагам подключает сервис, медиашлюз для картинок и видео и каждую площадку, проверяет каждый шаг через `doctor`; находит, что сломалось, когда публикация упала на настройке |
| `amplify:crosspost` | показывает превью поста по каждой площадке, спрашивает, публикует один раз и отдаёт ссылки |

Просите словами, «настрой кросспостинг в телеграм» или «опубликуй content/2026-09-13-release в телеграм и bluesky», или зовите скилл по имени: `/amplify:setup` в Claude Code, `$amplify:setup` в Codex.

Пост — это `content/<дата>-<слаг>/index.md`, только Markdown. Картинки и видео из той же папки уходят вместе с постом, если не сказать иначе. По умолчанию это обычный пост; рилс или сторис — по просьбе.

## Настройка

Адрес сервиса и токен выдаются на https://smmtp.ru, вопросы — на mail@smmtp.ru. Запустите `amplify:setup`. Значения живут в `.amplify/.config` проекта или в `~/.amplify/.config` для всех проектов и никогда не попадают в git; `.amplify/.config.local` рядом — пример без секретов, его можно коммитить. Оба файла начинаются с размеченного шаблона [scripts/config.template](scripts/config.template), а `amplify.py config` проверяет каждое значение перед записью, значения площадок — через сервис, если он отвечает. Каждый секрет идёт туда, куда выберете: в чат, в файл руками или в связку ключей macOS. Подробности — [configuration.md](skills/setup/references/configuration.md), откуда брать ключи каждой площадки — [platforms.md](skills/setup/references/platforms.md).

Команды, переменные и коды выхода, из этой папки:

```bash
python3 scripts/amplify.py --help
```

Python 3.9 или новее, только стандартная библиотека.
