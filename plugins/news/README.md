# News

Ищет новости в архиве: материалы по дате, категории, сайту, автору и языку, текст отдельного материала. Только чтение. Работает в Claude Code, Codex и Claude Cowork.

```
/plugin install news --marketplace htmlacademy/smmtp-marketplace
```

Остальные способы установки, включая отдельный скилл через `npx skills`, — в [README маркетплейса](../../README.md).

## Скилл

| Скилл | Что делает |
|---|---|
| `news:search` | превращает запрос в срез архива, забирает его и отвечает оригинальными заголовками со ссылками и датами; по просьбе добавляет тексты и пересказы |

Просите словами, «что писали про ИИ-агентов за неделю» или «собери новости по безопасности за сентябрь на русском», или зовите скилл по имени: `/news:search` в Claude Code, `$news:search` в Codex.

## Настройка

У сервиса есть адрес и ключ доступа, их выдают на https://smmtp.ru, вопросы — на mail@smmtp.ru. Положите их в `.env.local` в корне проекта, где работает плагин:

```
MELANGE_URL="https://<адрес сервиса>"
MELANGE_KEY="<ключ>"
```

Скилл этот файл никогда не создаёт и не правит. Когда строки на месте, скажите об этом агенту: он запустит `news.py doctor`. Тот сообщит, где нашёлся ключ, адрес сервиса, действителен ли ключ и сколько осталось от дневной квоты, ничего из неё не тратя. В Codex и Cowork хост из `MELANGE_URL` должен быть доступен из песочницы.

Команды, фильтры, вывод, коды ошибок и выхода, из этой папки:

```bash
python3 scripts/news.py --help
```

Python 3.9 или новее, только стандартная библиотека.
